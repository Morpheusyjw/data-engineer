## 二、防幻觉交叉验证（真实计算）

做法：对每条 issue 的 `evidence_quote`（须为葡语原文子串）做**原文包含性校验**——
比较前做宽松归一化（小写、压缩空白、去首尾标点），避免大小写与标点差异造成误判。

| 指标 | 结果 |
| --- | --- |
| issue 总数 | 15,752 |
| evidence_quote 为空 | 13（0.1%）｜大模型段 0 / 规则段 13 |
| 实际参与校验 | 15,724 |
| 命中原文（真实子串） | 15,717 |
| **证据命中率（防幻觉通过率）** | **99.96%** |
| ├ 大模型段命中率 | 96.70%（212 条参与校验） |
| └ 规则段命中率 | 100.00%（15,512 条参与校验） |
| 非空但未命中 | 7 条｜大模型段 7 / 规则段 0 |

> **口径说明**：`实际参与校验` 只统计「证据非空 **且** 能取到非空原文」的 issue。
> 本次另有 15 条因原文归一化后为空（纯符号如 `...`、`!!!`）未计入分母——
> 这类评价没有可校验的文本，计入分母只会让命中率虚高。

「非空但未命中」的 7 条**几乎全部来自大模型段**（212 条里 7 条未命中），
规则段命中率 100.00%。原因很直接：规则方法是**直接从原文切片**当证据，天然是真子串；
而大模型偶发把葡语原文改写/顺译成等价表达（语义没错，但不再是逐字原文），
这正是"防幻觉"真正要防的地方——因此 prompt 里强制「逐字摘抄」+ 生成后跑本校验，
比笼统要求"不要编造"有效得多。整体 99.96% 的命中率说明该约束基本生效，仍有 7 条漏网，
可作为后续迭代（如低 temperature + 校验不通过重试）的具体靶点。

校验逻辑（即本报告的计算方式）：
```python
raw = normalize(review_text[issue_review_id])   # 小写 / 压缩空白 / 去首尾标点
assert normalize(iss["evidence_quote"]) in raw, "幻觉证据"
```

**这张表比总数更能说明问题**：`other` 在规则段占 **50.6%**（7,860/15,540），
在大模型段只占 **3.8%**（8/212）。

- 规则段的一半落在 `other`，**不是**因为数据里真的没有可归类的问题，而是关键词表覆盖不到葡语的
  口语变体（拼写错误、缩写、整句抱怨）——这是方法本身的上限，不是数据的上限。
- 同一批数据换 Qwen2.5-7B 抽 212 条，`other` 只剩 3.8%，说明**七分类目是够用的**，
  需要补的是抽取能力，不是类别定义。
- 由此可以给出一个可决策的结论：若业务需要按类目做看板，规则段只能做「有没有问题」的粗筛，
  细分必须走 LLM；把 LLM 段的比例从 1.3% 提上去，
  才是这套 pipeline 下一步最值得花的钱（成本外推见 `cost_report.md`）。

## 四、字段口径：`evidence_quote_en` 为什么大面积为空

| 事实 | 数量 | 说明 |
| --- | ---: | --- |
| 规则段 issue 数 | 15,540 | `evidence_quote_en` 为**空字符串** |
| 大模型段 issue 数 | 212 | 由模型直接输出英文翻译 |
| `issues` 为空数组的条数 | 7 | 原文只有标点/无法读出诉求，规则与模型都没能给类目 |

两条口径先说清楚，避免误读为「字段缺失」：

1. **空串是设计选择，不是漏填**。规则方法只做关键词归类，不产生翻译；为了让下游能统一按
   `evidence_quote_en` 是否非空来区分来源（也用于本报告的分段统计），规则段统一写空串而非
   `null`，schema 保持稳定。
2. **7 条空 `issues` 是真实结果**：这些评价原文只有 `...`、`!!!` 之类的符号，
   没有可抽取的事件。保留它们（而不是伪造一条 `other`）是为了让「覆盖率 = 100%」这个断言
   不掩盖信息损失；下游若需一条不漏，应把 `issues` 为空视为「待人工看」的队列。

## 五、最终人工校验方法（抽样 30 条，可按需执行）

自动指标只能证明「结构合法 + 证据不臆造」，**语义正确性**仍需人工对齐：

1. 从 14,447 条中按 `category` 比例**分层抽样 30 条**（保证每类都有覆盖）。
2. 人工阅读原文，独立标注每个 issue 的 `category` / `severity`。
3. 计算：**类别准确率** = 与人工一致数 / 30；**严重度一致率** = 一致数 / 30；**证据命中率**同上。
4. 分歧样例回流优化 `prompt_template.txt`（尤其 category 边界样例）。

> 说明：本环境无人工标注资源，故语义准确率给出的是**可执行流程**而非虚构数字；
> 上表的结构/覆盖/防幻觉三类指标是真实计算值。真实 LLM 模式返回模型自估 `confidence`，
> 可作二次筛选阈值；规则降级模式置信度统一 0.5。
